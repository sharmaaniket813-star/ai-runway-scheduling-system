# ✈️ AI-Assisted Runway Scheduling System
> Final Year Project — BSc Computer Science, Aston University (2025–2026)

A full-stack web application simulating intelligent runway scheduling 
for Birmingham Airport (BHX), using live flight data and real-time 
weather to optimise arrivals and departures.

---

## 🚀 Features

- 🛬 Live radar scope for BHX approach traffic
- ⚖️ ICAO wake-vortex separation logic (Heavy / Medium / Light)
- ⏱️ Delay detection — flights delayed over 30 mins get HOLD status
- 💷 Fuel cost and CO₂ impact calculated per delayed flight
- 🌦️ Real-time weather integration for Birmingham Airport

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Python (no external dependencies) |
| Frontend | HTML, CSS, JavaScript |
| Flight Data | AviationStack API |
| Weather | OpenWeatherMap API |
| AI Scheduling | Rule-based ICAO separation engine |
